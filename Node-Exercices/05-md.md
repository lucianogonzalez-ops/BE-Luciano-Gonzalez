¿Qué diferencia hay entre fs.readFileSync y fs.readFile? ¿Cuándo conviene usar cada una?

La diferencia esta en si bloquean o no la ejecución del programa mientras leen el archivo

readFile No bloquea el programa  node sigue ejecutando el resto del codigo mientras el archivo se lee de fondo

readFilleSync Se ejecuta linea por linea  de forma bloqueante el programa se bloquea esperando a que termine de leer el archivo antes de seguir
