¿Qué es Node.js? ¿Es un lenguaje, un framework o un entorno de ejecución?

Node.js no es un lenguaje ni un framework  es un entorno de ejecución para JavaScript


¿Qué diferencia hay entre ejecutar JavaScript en el navegador y ejecutarlo con Node.js?

Navegador                                   Node.js
Interactuar con una página web	            Ejecutar scripts en el servidor/sistema

Tiene acceso al UI                          No tiene acceso al UI

¿Por qué window y document no existen en Node.js? ¿Qué objeto global tiene Node en su lugar?

window representa la ventana del navegador.
document representa el HTML de la página (el DOM)
Node al ser un entorno de ejecucion no tiene ese scope
