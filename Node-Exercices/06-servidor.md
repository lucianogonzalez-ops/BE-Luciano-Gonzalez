¿Qué es un servidor HTTP y qué hace el módulo http de Node?
un servidor http es un sistema que escucha un puerto en especifico para poder recibir pedidos y devolver respuesta a los clientes

El modulo http de node, nos sirve para poder crear ese servidor.


¿Qué representan req y res en un servidor de Node?
El Req, representa la request del cliente.
El Res, representa la response del servidor


¿Qué es un puerto y qué significa que un servidor "escuche" en el 3000?
Un puerto es un numero que indentifica un canal, para poder enviar o recibir datos, es como la altura de una puerta, dentro de una calle(direccion ip )



¿Qué es localhost?
el local host es el nombre de dominio que usa nuestra computadora para referirse a si misma


¿Qué hace curl y por qué es útil para probar un servidor sin usar el navegador?

curl es una herramienta de red que nos permite ver que se envia y que se recibe, aclarar que esto es sin irtefaz grafica, y talvez necesitamos especificar los datos que queremos recibir
